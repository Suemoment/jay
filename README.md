# 校园生活记账工具

## 项目介绍

面向在校学生的轻量级生活费记账网页，帮助记录日常消费、查看分类支出，并获得简单的省钱建议。应用使用浏览器本地存储，不需要注册账号或后端服务。

## 功能清单

- **账单记录：** 输入金额、选择食堂/外卖/网购/其他分类并填写备注。
- **账单查看：** 展示账单明细和累计支出。
- **消费饼图：** 汇总各分类支出金额及占比。
- **消费分析：** 根据账单生成消费概况和学生日常省钱建议；采用本地规则分析，不调用外部 AI 服务，也不会上传账单。
- **PWA 离线使用：** 支持安装到桌面；首次联网访问后缓存页面及本地资源，可离线打开。
- **数据持久化：** 账单保存在当前浏览器的 `localStorage` 中。

## 开发环境

- HTML5、CSS3、原生 JavaScript
- Chart.js 4.4.8（项目内本地资源）
- 支持 `localStorage` 和 Service Worker 的现代浏览器，建议使用最新版 Chrome 或 Edge
- Python 3（用于启动本地静态服务器）

## 运行方式

在项目根目录执行：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。也可以部署到支持 HTTPS 的静态网站托管服务。

> PWA 安装和离线功能需要通过 `localhost` 或 HTTPS 访问；直接双击打开 `index.html`（`file://`）无法注册 Service Worker。首次访问时请保持联网，以完成离线资源缓存。

## 使用说明

1. 在“记一笔”填写金额，选择消费分类，可选填写备注，然后点击“添加账单”。
2. 在“账单明细”查看记录和累计消费；刷新页面后，保存在当前浏览器中的账单仍会保留。
3. 点击“生成消费饼图”查看各分类支出占比。
4. 点击“开始分析账单”查看消费汇总和省钱建议。分析在本地完成，不会上传数据。
5. 浏览器满足安装条件时，点击页面上的“安装到桌面”；也可使用浏览器菜单中的安装选项。安装并完成首次联网缓存后，可离线打开应用。

> 账单仅保存在当前浏览器和网站来源下。清除该网站的浏览器数据可能会删除已保存的账单。
